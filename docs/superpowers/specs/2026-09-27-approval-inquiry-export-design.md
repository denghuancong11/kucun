# 审批中心询库 Excel 导出设计

## 目标

在审批中心增加“导出询库”，每次点击主动调用现有 `/api/approvals`，把该次响应中当前角色有权查看的全部硒鼓与墨盒询库单据生成 `.xlsx`。导出忽略页面筛选、待办范围、型号折叠状态和本地表单草稿；不混入调拨，也不读取定期隐藏的历史单据。

## 数据与权限

沿用 `fetchApprovals(role)` 与现有 `/api/approvals`。该接口已执行类别权限、运营/助理团队范围、单据状态和审批中心定期隐藏规则。导出只读取这次响应的 `inquiries`，不得使用 React Query 缓存或筛选后的页面分组。请求失败时显示错误并停止；没有询库时提示用户且不下载。

## 文件内容

工作表只包含下列 11 列，顺序固定：型号、商务部审核数量、供应商库存回复、发货仓库、采购备注、调拨部门、调拨店铺、调拨运营、已贴FNSKU、提交时间、状况。每单一行，同型号单据不合并。提交时间使用 `createdAt` 和页面现有 `displayTime` 口径。两项数量各自读取当前字段，空值留空，0 保持为数值 0。所有文字单元格显式按文本写入，保留前导零、中文、换行与公式样式文本。

采购回复 0 且由采购自动归档时，状况写“无货归档”；助理归档写“已完成”；其他阶段使用接口现有中文状态。采购回复字段与商务审核字段不在导出时重算或回填。

## 实现边界

前端在审批中心加入单一导出入口和请求中状态。点击时主动重新请求接口，并以该次成功响应生成文件；错误、空数据均不回退到缓存，不改变页面筛选或草稿。复用现有表格和通知样式，不增加后端接口、数据库结构、汇总行、业务列或报表配置。

## 验收

- 在隔离数据库的真实页面中下载并读取 `.xlsx`，验证文件结构、11列表头及顺序、数值/文本类型、数值 0、空值、状态和特殊文本。
- 验证硒鼓、墨盒、同型号多单、筛选无关、团队/类目权限、计划隐藏历史、跨客户端新回复、草稿隔离、请求失败和空结果行为。
- 导出前后单据、库存及事件记录一致。
- 运行新增页面回归、现有审批页面回归、类型检查、lint、构建和相关业务测试。
